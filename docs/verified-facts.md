## Known weak points

- **Hours are a moving target.** The shop changes them by season and posts
  closures on Instagram. The site states the posted Thursday–Sunday schedule,
  flags the winter pattern in prose, and points at Instagram. The open/closed
  widget assumes the standard schedule and will be wrong during a closure.
- **Image resolution.** Photos are cropped from screenshots, so the small
  gallery tiles are ~230 px. Originals would be a straight swap.
- **The order link is Google's.** It is the listing's own “Order online”
  action. The brief supplied it with `hl=zh-Hans-JP&gl=jp` plus one-off `gei` /
  `ei` / `utm_source` session parameters, which would have forced Chinese
  chrome on an English audience. The site uses the same `cvd` payload with
  `hl=en&gl=ca` and the session parameters dropped — checked live, it opens the
  order viewer for this shop. It is still a Google-owned URL: if it ever stops
  resolving, point the buttons at the listing itself
  (`https://maps.google.com/?cid=7511922284746744062`).
